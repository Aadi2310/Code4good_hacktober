# P2 implementation decisions

- The repository did not yet contain the backend scaffold, shared contract, label synonym reference, or P1 `PipelineError`. `backend/vyom/models.py` is copied verbatim from Section 0.4 of the P2 instructions as a bootstrap; `docai/_compat.py` uses `vyom.errors.PipelineError` automatically once P1 adds it.
- The specific P2 instructions replace the README's PyMuPDF choice with pypdfium2 plus pdfplumber to avoid an AGPL dependency.
- RapidOCR's current official installation is `rapidocr` plus `onnxruntime`, not the older `rapidocr_onnxruntime` package. Both import forms are supported by the adapter, with `rapidocr` preferred. This package pair was installed and smoke-tested on CPU.
- PDF text extraction works independently of OCR. OCR and QR are imported lazily; missing OCR produces a degradation reason for PDFs with a text layer and `NO_EXTRACTOR_AVAILABLE` for image-only input.
- OpenCV adaptive thresholding is used for deskew masks; scikit-image is not required in the base P2 dependencies. TrOCR, VLM, CUDA, and model weights outside RapidOCR are not part of this slice.
- Label synonyms have built-in English defaults until P1 supplies `reference/label_synonyms.yaml`.
- P4's representative invoice samples were not in the repository at implementation time, so local integration coverage uses synthetic fixtures and does not claim accuracy on real GST invoices.
